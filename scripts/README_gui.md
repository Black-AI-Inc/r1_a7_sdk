# R1-7A GUI 控制台

入口：`gui_control.sh`。Qt 桌面窗口提供关节、末端位姿、参数三个页签，实时显示目标/命令/反馈数值，
以及从 SDK 原始 URDF 与 STL 网格加载的三维机械臂。默认使用模拟驱动，不打开串口。

DEX1-1 的可选重力补偿、安装参数和初调步骤见 [README_gravity.md](README_gravity.md)。
调优配置下默认以 100% 开启（见下文）；`--profile legacy` 下需要显式指定 `--gravity-profile` 和 `--gravity-scale`。界面显示补偿比例及七轴前馈力矩。

## 调优配置（2026-11-07 起默认）

键盘控制和 GUI 默认使用 `--profile tuned`，即 2026-11-03 在 R1-7A + DEX1-1 实机上验证过的参数（见 `tuned_profile.py`）：

| 项目 | tuned（默认） | legacy（`--profile legacy`，原默认） |
|---|---|---|
| 增益 | J2、J4：Kp 200 / Kd 1.41；其余关节 100 / 1 | 全部关节 Kp 60 / Kd 0.5 |
| 重力补偿 | 100%，使用 `config/dex1_gravity.json` | 关闭 |
| 关节积分外环 | ki 1.5/s，每关节力矩权限 3 N·m | 无 |
| 跟踪误差停止阈值 | 0.1 rad（Kp 200 时约 20 N·m） | 0.2 rad |
| 软故障（心跳丢失、跟踪超限、非法目标等） | **阻尼保持，不释放力矩**；可恢复 | 释放力矩 |
| 连接时有关节略微越限 | 不超过 0.2 rad 时自动移回（例如释放力矩后 J6 落到限位外） | 拒绝使能 |

- **防振荡**：积分在关节越过参考后保持不变，不会在静摩擦带内来回跳。参考刚停下的 0.5 s 内不作这一判断。
- **实测（2026-11-03）**：10 mm 单步误差 0.26–0.66 mm，静置 0.62 mm，阻尼漂移 0.02 mm。
- **覆盖参数**：命令行显式给出的参数优先于配置。显式给出不同的 `--kp`/`--kd` 时，改为全部关节统一增益，积分仍为 3 N·m。
- **恢复**：阻尼保持时，键盘窗口按 **Enter**，GUI 点 **恢复 · Recover**，即在当前实测位置恢复位置保持。Esc 或“停止”仍会释放力矩。
- **GUI 参数页**：“应用参数”时，如果 Kp/Kd 没有改动，保留逐关节增益；改了 Kp/Kd 则改为统一增益。“恢复推荐值”填入的是当前配置的推荐值。

## 运行

本机依赖和驱动已安装、编译：

```bash
# 模拟：自动连接理想位置驱动，可以直接操作界面
./scripts/gui_control.sh

# 真机模式：打开窗口后点击“连接真机”，才会打开串口并使能当前位置保持
./scripts/gui_control.sh --execute --port /dev/ttyUSB3
```

真机启动不自动回零或进入 P 点。点击连接后，以当前关节反馈初始化命令和滑块，避免沿用
上一次窗口的目标。连接前请关闭键盘控制或其他占用同一串口的程序。

## 界面使用

1. 选择 **Joint 关节控制**：J1–J7 滑块或右侧数字框设置目标角度，单位为度，范围来自 URDF。
   滑块下方显示平滑命令角度与实际反馈角度。数字框可键入数值后按 Enter，也可用上下箭头微调。
2. 选择 **末端位姿**：X/Y/Z 设置 TCP 在 `base_link` 中的绝对位置（mm）；
   Roll/Pitch/Yaw 设置绝对朝向（°）。采用固定轴 XYZ 欧拉角，旋转矩阵为 `Rz(Yaw) Ry(Pitch) Rx(Roll)`，
   与 URDF RPY 和 SciPy `Rotation.from_euler("xyz", ...)` 一致。
   改位置时保留所选朝向，改旋转时保留所选 XYZ；六维目标经 IK 校验后执行平滑关节运动。
   右侧显示各自的目标、命令、反馈。输入角度保持用户选择的表示；命令/反馈采用标准欧拉角，
   ±180° 附近可能显示跳变，但 IK 使用旋转矩阵，等价角度不会导致一圈旋转。
   Pitch 接近 ±90° 时欧拉角存在奇异性，宜小幅调整。
3. 选择 **参数**：修改速度、加速度、jerk、增益和保护阈值；点击“应用参数”后才生效。
   右列始终显示驱动确认的当前值。“恢复推荐值”只填入默认值，仍需点击应用。
4. 右侧 **URDF** 可切换“实际反馈”“平滑命令”“目标预览”。左键拖动旋转、滚轮缩放，
   “复位视角”恢复初始相机。模型的红/绿/蓝轴分别代表基坐标 X/Y/Z，橙色球表示 TCP 原点
   （位于模型内部时可能被遮挡）；TCP 的短三色轴随末端朝向旋转。
   窗口和三维视图均为全白背景，各区域通过留白和标题区分，不使用边框。

**滑块是目标位置控制：松开滑块后继续平滑到目标。** 这与键盘点动的松键保持不同。
点击保持/按空格，或窗口失焦，会取消剩余运动并保持当前已发送的命令位置。
切换关节/末端位姿模式或进入参数页会取消旧目标，收到保持确认后再同步滑块。

| 按钮 / 快捷键 | 行为 |
| --- | --- |
| P · 准备姿态 / P | 平滑到默认 Home −Y 5 cm、+Z 5 cm 的准备姿态，保持 Home 朝向 |
| H · 回零 / H | 平滑到已标定七轴零位 |
| 保持 / Space | 冻结当前命令位置并持续保持，取消尚未完成的 IK 和后续目标 |
| 停止 / Esc | 释放力矩并锁定控制；需要断开后重新连接才能继续 |
| 断开 / 关闭窗口 / Ctrl-C | 停止、释放力矩并关闭连接 |

P/H 操作会切回 Joint 模式。默认准备姿态、`--tcp` 和 `--ready-q` 与
[键盘控制](README_keyboard.md)一致。零位附近存在关节限位，建议先用 P 进入准备姿态再做 XYZ 调整。

## 数值和模型的含义

- **目标**：用户选择的位置，或通过 IK 解出的关节角。XYZ 求解未完成时，模型明确显示“上一有效目标预览”。
- **命令**：100 Hz 平滑轨迹当前发送给驱动的位置。
- **实际反馈**：SDK 收到的编码器关节角；TCP 反馈由这些角度通过 FK 计算，非外部位置传感器测量。
  停止后会标明“最后收到的反馈”，断开时清空反馈读数。
- 模拟模式的反馈采用理想跟踪，不模拟重力、机械惯性或碰撞。URDF 视图仅用于显示姿态，不执行物理仿真。

IK 和 URDF 渲染分别在独立进程运行；驱动仍由独立 C++ 进程保持 100 Hz 控制。
反馈约 20 Hz，三维视图最高约 12.5 Hz，实际显示帧率取决于机器性能。
只保留一个在途 IK 和最新滑块目标，过时结果不会重新触发运动。
新位姿求解期间上一有效轨迹继续执行；求解失败或校验失败时保持。固定朝向始终参与求解，
不会通过放松朝向换取位置成功。搜索依次使用当前命令附近 ±0.6 rad、±1.4 rad、完整 URDF 关节范围，
每一级均与真实关节限位取交集；小幅目标命中后立即返回，较远目标再启动多初值搜索。
符号 FK 和解析雅可比每个 IK 进程只构建一次，通过有界最小二乘求解，最终独立 FK 检查
位置误差 ≤0.1 mm、方向误差 ≤0.001 rad。优先寻找当前姿态附近的解，不保证全局最近解。
一次请求从入队起共用 3 秒墙钟预算（全部重试合计），GUI 另留 0.5 秒通信/调度余量；
超过 3.5 秒未收到有效结果则保持并重启 IK 进程。新目标停止编辑 80 ms 后，
运行超过 150 ms 的过时求解会被取消，避免它占用新目标的搜索时间。
状态栏显示成功搜索的级别及求解耗时；搜索未找到解不再直接称为“不可达”。
工作空间并非矩形；扩大搜索不能保证所有几何可达位姿都被数值算法找到。
轨迹仍为关节空间平滑，目标位姿固定朝向不等于中间路径也严格保持朝向。

保持和规划沿用命令参考，不反复用反馈角覆盖参考，保留此前修复的 PD 承重静差。
GUI 默认参数保持原来的保守设置，可在参数页或启动参数中调整：

| 参数 | 推荐默认值 | 可设置范围 | 启动参数 |
| --- | --- | --- | --- |
| 各关节最大速度 | 0.15 rad/s（约 8.59°/s） | 0.01–1 rad/s | `--joint-speed` |
| 各关节最大加速度 | 0.5 rad/s² | 0.1–5 rad/s² | `--joint-accel` |
| 各关节最大 jerk | 2 rad/s³ | 0.5–50 rad/s³ | `--joint-jerk` |
| Kp | 60 | 0.01–100 | `--kp` |
| Kd | 0.5 | 0.01–5 | `--kd` |
| 命令领先暂停阈值 | 0.08 rad | 0.01–0.3 rad | `--lead-limit` |
| 跟踪误差停止阈值 | 0.2 rad | 0.02–0.5 rad | `--tracking-limit` |
| 单目标运动超时 | 60 s | 5–300 s | `--move-timeout` |

这些是应用程序的可配置范围，不是机械臂在所有负载下的额定安全范围。
速度是关节角速度上限，不是 TCP 的线速度或姿态角速度。
暂停阈值必须严格小于停止阈值；界面和原生驱动分别校验，非法设置整组拒绝。
应用设置时取消旧目标及在途 IK，在当前命令处 HOLD，再一次性更新全部参数；
确认前禁用运动输入，确认超时停止。不会通过重新连接或反馈角重置承重参考。
右列读数来自驱动 `config` 回报；输入框为尚未应用的草稿。
设置在当前窗口内断开重连时沿用，关闭窗口后不保存；下一次启动使用推荐值或命令行参数。

```bash
./scripts/gui_control.sh --execute --joint-speed 0.15 --joint-accel 0.5 --joint-jerk 2
# 可配置实际工具 TCP，单位 m/rad
./scripts/gui_control.sh --tcp 0 0 0.08 0 0 0
```

正常运动采用 Ruckig 平滑；保持/停止/跟踪保护优先中断，不为了完成减速而继续运动。
所有目标及整段关节轨迹都检查 URDF 限位；命令领先反馈超过暂停阈值时暂停推进，
跟踪误差超过停止阈值、反馈异常或 GUI 心跳超时会停止并释放力矩。
URDF 关节限位、反馈新鲜度 0.2 s、GUI 心跳 0.5 s 保护始终启用。
GUI 的完整关节目标使用 `MOVE`；运动超时设置作用于 MOVE / HOME / READY，
键盘小步 `TARGET` 的 0.12 rad 和 5 s 限制保留，键盘 CLI 自身速度范围保持不变。
原生协议新增 `config` capability：`CONFIG 序号 speed accel jerk kp kd lead tracking timeout`，
状态中的 `config_ack` 标识已处理的请求，`config_revision` 标识成功应用的请求，
`config_error` 给出拒绝原因；停止锁定状态拒绝重新配置/使能。
没有自碰撞、工具或环境碰撞规划；关节空间平滑不保证 TCP 严格直线运动。停止功能不是硬件急停。

## 安装与验证

Ubuntu / Python 3.12，源码仍需位于完整 SDK 内（包括 URDF 和 STL）：

```bash
cd r1-7a_sdk   # 仓库根目录
./scripts/setup_gui.sh
./scripts/gui_control.sh
```

安装脚本选择 `R1_IK_PYTHON` → SDK `.venv-ik`；都不存在时创建 SDK 的 `.venv-ik`。
它安装 [requirements-gui.txt](requirements-gui.txt)，构建独立驱动；Ubuntu 缺少 `libxcb-cursor0` 时，
从系统配置的 apt 仓库下载并解包到 `build/gui-runtime/`，不需要 sudo、不修改系统安装。
启动器会加载这份本地 Qt 运行库。安装需要网络，运行使用本地依赖与模型。

源码：`gui_control.py`（Qt UI）、`gui_control_core.py`（控制与异步 IK）、`gui_urdf.py`（URDF 渲染）、`gui_settings.py`（参数定义）。
界面使用 [Qt for Python](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSlider.html)，
模型通过 [PyBullet 本地渲染接口](https://github.com/bulletphysics/bullet3/blob/master/examples/pybullet/examples/testrender.py)显示。
IK 来源与坐标约定见 [README_ik.md](README_ik.md)，轨迹来源见 [README_keyboard.md](README_keyboard.md)。

离线验证：

```bash
.venv-ik/bin/python -m pytest -q tests/test_gui_control.py tests/test_keyboard_control.py tests/test_arm_control.py
ctest --test-dir build/keyboard --output-on-failure
```

日志默认在 `build/keyboard/logs/gui-时间戳.jsonl`，可用 `--log /path/to/gui.jsonl` 指定。
覆盖滑块操作、实际 Qt 窗口与模型渲染、URDF/FK 一致性、异步结果作废、超时/不可达处理、
模式切换、三轴旋转保持目标 XYZ、参数确认/拒绝/恢复默认、原生轨迹限速及保护阈值生效、
保持承重参考、停止锁定与退出清理。全部控制测试使用模拟驱动，未驱动真机。
